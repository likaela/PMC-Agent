## 1. 项目基本信息

### 项目名称

**PMC-Agent / 制造业智能计划助手**

### 项目定位

基于大语言模型 Agent 的制造业 PMC（Production Material Control，生产物料控制）辅助决策系统。

项目目标是开发一个面向中小制造企业的 AI 智能助手，模拟经验丰富的 PMC 计划人员，根据企业生产数据自动完成：

- BOM 物料展开
- 物料需求计算（MRP）
- 库存齐套分析
- 缺料风险识别
- 采购建议
- 生产调整建议

最终输出结构化 PMC 分析报告。

---

# 2. 项目背景

制造企业生产过程中，经常需要回答：

> “我要生产 1000 台产品，现在库存够不够？缺哪些物料？需要采购多少？会不会影响生产？”

传统方式：

人工查看：

- BOM表
- 库存表
- 采购订单
- 生产计划

然后经验判断。

问题：

- 数据量大
- 容易出错
- 响应慢
- 经验依赖强


PMC-Agent 希望通过：

```
LLM理解需求
+
Python业务计算
+
企业数据
+
规则引擎
```

实现智能辅助决策。

# 3. 核心设计理念

项目遵循：

> LLM负责思考，代码负责计算，数据库负责存储，规则负责约束。


## LLM负责：

- 理解用户需求
- 判断任务类型
- 调用工具
- 生成分析报告


## Python负责：

- BOM展开
- 库存计算
- 缺料计算
- 采购数量计算
- 风险判断


禁止：

让 LLM 自己计算库存、生产数量等确定性业务。

# 5.2 BOM Tool

文件：

```
tools/bom_tool.py
```


当前功能：

输入：

```
产品型号
生产数量
```


输出：

物料需求。


目前示例：

```
ABC-1000

主板 ×1000
电机 ×2000
螺丝 ×8000
```


当前限制：

- 只有单层BOM
- 数据硬编码
- 未支持Excel


未来：

支持：

```
整机

↓

模块

↓

零件

↓

原材料
```

多层BOM递归。

---

# 5.3 Inventory Tool

文件：

```
tools/inventory_tool.py
```


当前功能：

根据库存判断缺料。


示例：

需求：

```
主板 1000
```


库存：

```
主板 800
```


输出：

```
缺料200
```


当前限制：

库存数据硬编码。


未来支持：

库存：

- 当前库存
- 已占用库存
- 在途采购
- 安全库存
- 批次
- 有效期


---

# 5.4 Purchase Tool

文件：

```
tools/purchase_tool.py
```


当前功能：

根据缺料生成采购建议。


例如：

缺料：

```
200
```


安全库存：

```
100
```


建议采购：

```
300
```


当前限制：

- 无供应商
- 无真实采购周期
- 未接入采购系统
