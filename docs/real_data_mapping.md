# 真实企业数据字段映射与一期假设

## BOM

- 文件：`data/raw/10 KQ-Z112 BOM 969T0Z1120101  23.xls`
- 参与工作表：`BOM`
- 元数据来源：BOM 工作表第 2 行的“项目代号”和“版本号”，当前读取为 `KQ-Z112` 与 `V01`；父项和版本不从文件名推断。
- 排除工作表：`版本说明`、`加工原材料`、`生产说明`。

| 原始字段 | 内部标准字段 | 一期计算 | 清洗/聚合规则 |
| --- | --- | --- | --- |
| 项目代号（元数据） | `parent_material` | 是 | 从元数据正则提取并校验 |
| 版本号（元数据） | `version` | 是 | 从元数据正则提取并校验 |
| 料 号 | `child_material` | 是 | 去除单元格空白；数值型料号转为无 `.0` 的字符串 |
| 数量 | `qty_per` | 是 | 必须为正整数；每一行是一条 BOM 关系 |
| 名称、规格型号、位号、备注 | 原始审计信息 | 否 | 不进入一期 MRP 数量计算 |

当前业务假设：一期仅使用 `BOM` 工作表中 66 条有效关系；该 BOM 是单层关系，后续服务仍可递归展开标准关系。

## 库存与料号主数据

- 文件：`data/raw/2026年库存表+料号查询表及成品库存表(1).xlsx`
- 一期库存工作表：`库存表`。
- 排除库存来源：`电阻电容现库位`、`成品库存表`、`2023年至2025年形成的存货-可以处理`、`阻容库存表-2019`。

### 库存表

| 原始字段 | 内部标准字段 | 一期计算 | 清洗/聚合规则 |
| --- | --- | --- | --- |
| 物料代码 | `material_code` | 是 | 转为稳定字符串；按该字段聚合 |
| 库存 | `stock` | 是 | 仅汇总 `库存表` 的明细行；接受非负整数或小数并保留原始数量精度 |
| 归属地 | `site` | 保留明细 | 不参与一期数量汇总 |
| 库位 | `location` | 保留明细 | 不参与一期数量汇总 |
| 批次号 | `batch` | 保留明细 | 不参与一期数量汇总 |

一期默认假设随每个聚合库存记录的 `source_assumptions` 输出：`reserved = 0`、`incoming = 0`。`safety_stock` 在原始库存表中未提供，标为 `not_provided_in_source`，绝不默认成 0。

### 料号查询表

使用 `料号查询表` 补充主数据：`名称`、`规格型号`、`封装`、`质量等级`、`品牌/厂商`、`备注`。主数据只用于匹配和展示，不改变 BOM 用量或库存数量。

### 成品库存表

`成品库存表` 由专用仓储读取并保留，当前不进入一期 MRP，也不与原材料库存自动合并。

## 供应商主数据

- 文件：`data/raw/供方导出.xlsx`
- 工作表：`导出`

| 原始字段 | 内部标准字段 | 一期计算 | 清洗/聚合规则 |
| --- | --- | --- | --- |
| 公司编号 | `supplier_code` | 否（主数据） | 去除首尾空白，作为供应商唯一业务标识 |
| 公司名称 | `supplier_name` | 否（主数据） | 去除首尾空白，保留展示名称 |
| 行业类型 | `industry_type` | 否（主数据） | 保留原始文本，不参与采购数量计算 |
| 供方等级 | `supplier_level` | 否（主数据） | 保留原始文本，不推导优选供应商 |
| 备注 | `remark` | 否（主数据） | 保留原始文本 |

清洗与聚合规则：只读取 `导出` 工作表第 2 行表头后的明细；当前不按供应商聚合，也不将其与物料、库存或 BOM 自动关联。

供应商文件只作为 supplier master。没有可靠的料号—供应商对应关系，因此一期不生成 `material_supplier_map`、`lead_time_days`、`safety_stock` 或 `incoming`，也不根据供应商主数据猜测这些字段。

## 已确认的库存错误记录与采购参数

业务确认的 22 个库存异常料号不再进入当前 MRP 输入；该清理只影响库存/MRP 范围，不删除或改写 BOM 关系。清单由 `repositories.real_inventory_repository.INVENTORY_DATA_ERROR_MATERIAL_CODES` 维护，并在报告中审计输出。

采购参数不维护统一 Excel。对已知缺料物料，流程逐项询问并补充 `supplier_code`、`safety_stock`、`lead_time_days`；在这些值提供前，供应商主数据不产生任何料号—供应商关系、在途、提前期或安全库存，也不生成真实采购建议。
