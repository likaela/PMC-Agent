# 智造 PMC Agent：合成版试用指南

本页面及远程试用只使用人工构造的演示数据，不接入真实企业BOM、库存或个人信息。当前仅支持 **DEMO-PMC-01 / V01**，请勿输入企业秘密。

## 可以体验什么

自然语言提问 → 任务理解 → Python确定性分析 → 中文结论与结构化结果 → 来源追问。不是让模型猜库存或决定开工。

| 推荐提问 | 合成案例结果 |
| --- | --- |
| 查询DEMO-PMC-01的BOM | 根BOM三条关系，展开四种叶子物料 |
| 生产50台DEMO-PMC-01 | 库存齐套，缺口0 |
| 生产100台DEMO-PMC-01 | 四项缺料，不能立即满足 |
| DEMO-PMC-01最多能生产多少台 | 理论最大75台 |
| 帮我生成采购建议 | 四项合成建议及成本；不代表已经采购或到货 |
| 为什么不能生产 | 复用当前分析证据解释原因 |
| 生产75台DEMO-PMC-01 | 刚好满足合成物料需求 |
| 生产76台DEMO-PMC-01 | 超过理论上限，存在物料不足 |
| 生产0台 | 提示数量须大于0，不执行物料计算 |

以上问题已在本地Vue正式构建→Caddy→FastAPI→隔离合成库中验收。公网HTTPS地址尚未开放，也未宣称已通过公网访问验收。

## 操作顺序

1. 使用组织者分配的个人试用账号登录，打开“分析工作台”。
2. 点击“新建分析”，输入50台问题，再输入100台问题，查看当前回答对应的右侧物料表。
3. 连续询问采购建议、原因或来源；来源区显示本次合成事实的BOM版本与数据时间。
4. 点击左侧历史回答，右侧切换为当时结果；历史并不表示重新查过最新库存。
5. 远程合成版刷新恢复当前会话；本地双模式页面刷新后先回到企业入口，须显式选择合成Demo恢复该空间的历史。

专用远程合成版的数据空间固定为“合成 Demo”，不提供本地企业或私有评审场景入口。账号A不能读取或续写账号B的历史；代理和后端仅监听本机，公网HTTPS入口需组织者另外批准。本次只完成本机生产构建验收，没有开启公网隧道。

当前不在公网试用中提供任何真实企业产品或真实库存。数量、库存与成本均是合成案例的确定性结果；齐套不构成设备、质量、排程或交付承诺。

连接失败时页面会提示重试，不会自动切换为假响应。会话失效/不属于当前账号时请新建分析；不要尝试共享他人的会话。试用结束后的历史保留由组织者管理。
