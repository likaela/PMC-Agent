# 企业 Agent 交互增强

企业前端继续使用 `/api/v1/agent/query`，创建或复用持久企业 `session_id`。公开请求、响应模型不变。

- 普通问候、能力介绍：Python 识别明确的非业务表达，返回能力说明；不执行业务 Tool，不清除原生产上下文，也不生成企业事实。
- 产品发现：“我能生产什么”“有哪些产品”等调用只读 `published_product_search`。只列出已发布 BOM 的父件、名称（缺失保留 null）、版本和来源，不从原始文件读取，不自动选定产品或版本。
- 名称筛选：“生产某类产品”仅用用户原文作字面筛选。当前没有权威产品分类事实，不做语义分类、相似匹配或猜测。无匹配则明确说明没有匹配的已发布 BOM 信息。
- BOM 父件可能是中间组件。产品发现不是可生产判定；需选定编码并提供数量后调用原有分析工具。目录按 BOM 版本行限制最多 100 条，截断时明确提示缩小查询范围。
- 缺产品或数量：说明已经理解的字段、待补充条件和后续输入方式；未补齐前不执行业务计算。数量未知的“最多能生产多少”仍可进入原产能查询。
- 缺版本：继续由现有 Context Resolver 核验。唯一有效版本可补全并记录证据；多版本不自动选择；无有效 BOM 时提示确认已发布版本及业务日期。
- 产品目录和普通交流不会覆盖原业务任务。后续原因追问仍复用已保存 Evidence，不重新执行计算。

## 数据与 Demo 隔离

产品 Tool 绑定当前企业会话的 Store，不进入旧 Demo Tool 列表。结果沿用 `status/query/data/completeness/provenance/warnings`，来源包含文件、SHA-256、工作表、导入批次和 BOM 版本；名称存在时保留其主数据来源。

前端首次进入及刷新都不自动选择 Demo。企业历史可按企业指针恢复；Demo 历史只有用户显式选择合成 Demo 后才能恢复，继续核验原 `scenario_id`。环境变量、URL 和旧浏览器偏好不构成 Demo 选择授权。

未修改数据库结构、发布流程、核心计算 Service、LangGraph 或 Demo 数据。DeepSeek 不生成目录、库存数字或生产结论。
