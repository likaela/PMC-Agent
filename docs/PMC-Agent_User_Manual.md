## 第一章 产品简介

PMC-Agent是面向制造企业PMC计划员、物料管理员和生产协调人员的智能生产计划助手。它用于**生产计划下达前的物料需求核对**：查看产品组成，按目标数量计算需求，核对接入的库存记录，再解释不足原因和数据来源。

您可以直接输入“生产1片KQ-Z112可以吗？”，也可以先查BOM、再调整数量。系统根据当前产品和本次问题调用相应查询与计算功能，不要求您了解程序或数据库。

### 1.1 三个基本概念

| 概念 | 通俗解释 |
|---|---|
| BOM（物料清单） | 描述产品需要哪些组件或材料，以及生产一个父项所需的数量。 |
| 物料齐套 | 在本次分析范围内，各项物料的数量都能满足目标需求；不等于设备、质量和工单条件都已满足。 |
| 缺料分析 | 对已有可核实库存的物料比较需求与库存，列出不足数量；没有库存记录的物料仍是未知。 |

### 1.2 一般操作路径

1. 查看产品目录，选择产品和分析范围。
2. 查询BOM和库存记录。
3. 提供大于0的整数生产数量。
4. 阅读结论，查看物料需求和不足项。
5. 继续询问原因，或打开来源记录核对依据。

系统不会因为缺少记录而编造库存、价格或到货承诺。当前数据不包含实时ERP库存同步；页面上的“即时计算”指根据已接入数据执行本次核对。

## 第二章 进入系统与界面说明

### 2.1 访问入口

本手册适用于管理员已经启用且已授权的数据环境。**地址存在不代表服务当前已启动**；网页打不开时，请先联系项目组，不要自行修改配置。

| 入口 | 本机地址 | 页面及访问范围 |
|---|---|---|
| 本地开发页面 | http://127.0.0.1:5173/ | 有首页，可进入“分析工作台”；企业资料需管理员完成本地授权配置。 |
| 授权工作台 | http://127.0.0.1:8090/ | 登录后直接进入工作台；有三产品权限的账号可访问本手册全部目录。 |
| 独立演示版 | http://127.0.0.1:8080/ | 仅DEMO-PMC-01，不提供两个企业产品及其当前配置数据。 |

本轮文档核对时8090未监听，未为编写手册启动任何服务。此前本机验收地址可供管理员参考，**尚无正式公网HTTPS链接**。如果项目组以后提供远程地址，应使用其单独发放的网址和个人账号。

“127.0.0.1”指您正在使用的电脑。把这个地址发给老师或同学，他们访问的是自己的电脑，不会连接到您的系统。

### 2.2 本地首页

本地首页显示产品简介和使用路径。点击**“开始分析”**进入空白企业工作台，不会自动选择演示产品。首页的企业分析卡片用于进入工作台，不会直接产生业务结论。

需要体验演示产品时，主动点击**“体验演示产品”**，再选择问题进入工作台。部分入口只预填问题，仍需您发送；请观察输入框，不要把首页说明当作已执行结果。

授权工作台和独立演示版不使用这一首页，打开后直接显示其对应工作台。

### 2.3 工作台各区域

| 区域 | 实际作用与操作 |
|---|---|
| 顶部产品与范围 | 授权工作台有“选择产品”和“分析范围”。选择后核对产品、版本、物料项数及单位。 |
| 顶部摘要卡片 | 本地工作台有“查询对象”“分析状态”“数据来源”；涉及有效数量时才显示“目标数量”。授权工作台使用顶部范围说明，不一定有同样的四卡布局。 |
| 左侧对话区 | 本地页面标题为“PMC助手”，授权页面为“自然语言生产分析”；显示本次对话的问题与回答。点击已完成回答可查看对应结果。 |
| 智能查询 | 默认收起。点击“展开推荐问题”查看建议，点击“收起”折叠。点选推荐问题会发送查询并自动收起。 |
| 当前产品 | 输入框上方的小型标识；有可选产品时可点击下拉切换。未选中时显示“未选择产品”。 |
| 输入框 | 输入问题后点击发送图标；键盘Enter发送，Shift+Enter换行。中文输入法选字时不会误发送。 |
| 分析结论 | 右侧显示当前选中回答的结论、相关指标和明细；窄屏可能排列在聊天区下方。 |
| 物料明细 | 查看单耗、需求、库存、缺口及状态；提供搜索、状态筛选、名称排序和逐行来源入口。 |
| 数据来源与适用条件 | 默认折叠，点击“展开详情”或结果中的来源按钮查看。 |
| 新建分析 | 清空当前工作台对话并开始新的空白分析；不会删除企业事实。 |
| 恢复会话 | 在保有当前浏览器会话指针时恢复本次对话，不重新执行所有历史计算。 |

授权工作台另有**“产品物料目录”**按钮，展开后显示当前范围的编码、名称、BOM单耗、库存数量及单位；再次点击可收起。本地页面不保证存在此按钮，可发送BOM查询后使用“物料明细”。

### 2.4 输入和等待

1. 确认“当前产品”和分析范围。
2. 输入问题，例如“生产1片可以吗？”。
3. 点击发送图标，或按Enter。
4. 等待本轮回答，观察右侧结果是否与该回答一致。
5. 需要停止等待时点击“取消”。

取消只停止当前页面等待，服务端可能已经执行并保存结果。取消、超时或断线后先恢复会话，再决定是否重试，避免重复提交。

智能查询在刷新、产品切换、查看其他回答后保持紧凑。较窄窗口下请向下滚动查看结论，物料表可左右滚动，不需要更改浏览器设置。

## 第四章 可查询物料目录与编码使用

本手册[附录一](#appendix-materials)包含三份目录：KQ-Z112当前BOM34项、KQ-BHX3588M的91项BOM，以及DEMO-PMC-01的5条实际BOM关系。

### 4.1 先确定产品和范围，再复制编码

1. 选择产品并确认范围。
2. 授权工作台点击“产品物料目录”，或发送BOM查询。
3. 在表格中搜索目标物料。
4. 复制当前范围的有效编码，按附录的查询方法使用。
5. 查询后检查“当前产品”及来源，避免把另一产品的编号带入本次分析。

### 4.2 当前配置的MAT编号

例如MAT-053是当前BOM配置的稳定展示编号，并非企业全局物料主数据编码。**当前配置支持以这种编号查询对应记录**，已验收的问题是“查询MAT-053库存”。

编号只对当前配置有效，切换其他产品后应使用新产品目录。

“物料053”等名称是页面的展示名，不是原始企业名称；不要根据这个名称猜真实编码。本手册不提供私有编号对应表。

### 4.3 KQ-BHX3588M物料编码

附录中的KQ-BHX3588M目录保留准确编码与来源名称。选择该产品后，可输入“查询＋编码＋库存”。

### 4.4 Demo物料的使用限制

DEMO-MODULE-01是组件，不是另一主产品；DEMO-BOARD-01等是最终物料。可在演示产品的目录或生产明细中核对它们。

当前授权工作台的产品识别入口会将单独出现的某些DEMO开头的子料编码当作不可访问的产品，因此**本手册不将直接发送“查询DEMO-BOARD-01库存”或“查询DEMO-MODULE-01的BOM”列为可用操作**。

可靠方法是选择DEMO-PMC-01，查询产品BOM或执行生产数量分析，再在物料表搜索对应编码、点击“查看来源”。这不会改变活动产品，也不会把组件误当成主产品。

## 第五章 自然语言查询方法

以下推荐问法来源于当前代码及此前真实验收。先确认产品和范围；带有“它”“这个产品”的问题只补充未说明的对象，不会覆盖您本轮明确输入的新产品。

### 5.1 产品与BOM

| 目的 | 推荐输入 | 使用条件 |
|---|---|---|
| 查看目录 | 有哪些产品？ | 返回当前权限内的产品，不改变当前产品。 |
| 查看已发布BOM产品 | 查询已发布BOM的产品。 | 三产品工作台中会包含标为“演示产品”的Demo。 |
| 只看企业正式目录 | 只查看正式发布的企业BOM产品。 | 有两产品权限时返回KQ-Z112和KQ-BHX3588M。 |
| 切换到演示产品概览 | 查询演示产品。 | 目录中存在唯一可访问的演示产品。 |
| 查询产品概览 | 查询KQ-Z112。 | 使用当前34项配置。 |
| 查当前BOM | 看看它的BOM。 | 已选择产品。 |
| 查指定BOM | 查询KQ-Z112的BOM。 | 显示当前范围。 |
| 查物料组成 | 查看KQ-Z112有哪些物料。 | 当前配置显示34项；范围以顶部确认信息为准。 |

BOM单耗是每一个父项需要的数量。没有指定生产数量时，BOM查询不等于已经计算某批生产总需求。

### 5.2 库存与单料

- 已选KQ-Z112当前配置：输入“看看库存。”或“查询KQ-Z112的库存”。
- 已选KQ-BHX3588M：输入“查看对应库存。”。
- 已选KQ-Z112当前配置：输入“查询MAT-053库存”。
- 已选KQ-BHX3588M：复制当前目录中的准确料号，按“查询＋料号＋库存”提问。

单说“查看这项物料的库存记录”可能仍指向当前产品，而不是您刚浏览的某一行。请提供料号；点击表格行的来源按钮并不会自动将该行设为下一轮查询对象。

查询产品库存主要是查看其BOM关联材料的库存，不应理解为已经提供该产品的成品仓库存量。

### 5.3 指定数量生产需求

1. 输入“生产1片KQ-Z112可以吗？”。
2. 再输入“那生产2片呢？”。
3. 查看本轮目标数量、每项需求与不足数量。

KQ-BHX3588M可先输入“查询BHX3588M。”，再输入“生产10片需要哪些物料？”。“BHX3588M”是当前目录中的唯一简称，不需要重复完整编码。

数量应为大于0的整数。KQ两个产品的正式成品单位为片；在已确认的计件成品语境中，“生产1个”“生产1件”也能理解为目标数量1，结果按片显示。这不是所有单位之间的通用换算。

### 5.4 最大满足数量与原因

| 目的 | 推荐输入 | 说明 |
|---|---|---|
| KQ-Z112当前配置上限 | 最多能生产多少片？ | 当前34项最大满足1片，不代表完整产品产能。 |
| Demo上限 | 最多可以生产多少台？ | 演示产品理论最大75台。 |
| 解释上轮不足 | 为什么不能生产？ | 先执行相应数量分析，引用已有结果。 |
| 当前配置明确不足 | 为什么不能生产2片？ | 对应2片结果，已验收。 |
| 查看限制项 | 哪些物料限制产量？ | 当前范围和当前任务，不使用另一产品证据。 |
| 看具体缺口 | 查看右侧“缺口数量”列 | 需要数量分析结果；无记录的缺口仍未知。 |

“具体缺多少”和“当前库存最多支持多少台”这两种简写在当前Demo解析中不能可靠命中预期操作，不作为推荐问法。请改用上表的明确表达，而不是反复发送同一句。

### 5.5 来源与采购辅助

- 分析后输入“这些数量来自哪里？”，或点击“查看本次分析来源与适用条件”。
- 单项来源使用物料行的“查看来源”。
- Demo完成100台分析后，输入“针对缺料给出采购建议。”。
- 采购结果的物料、缺口、建议采购量、成本及已提供参数以当前返回明细为准。

两个企业产品当前不保证能生成完整真实采购数量、成本或供应商承诺。本手册不推荐在企业范围使用演示采购结果，也不介绍自动下单或邮件发送。

## 第六章 多轮对话与产品切换

### 6.1 何时沿用、何时切换

| 您的输入 | 系统处理 |
|---|---|
| “那生产2片呢？” | 沿用当前产品与范围，用新数量重新核对。 |

## 第八章 如何阅读分析结果

### 8.1 字段含义

| 页面信息 | 阅读方法 |
|---|---|
| 查询对象 | 本次结果针对哪个产品或物料，不一定等于正在查看的其他历史回答对象。 |
| 目标数量 | 本次指定生产的成品数量。缺少数量时不显示该卡片，不代表默认生产1个。 |
| BOM版本 | 本次使用的物料关系版本；KQ-Z112为V01-C34，其他两个产品为V01。 |
| 物料项数 | 当前查询范围的明细数量；Demo主BOM项数与展开后最终材料数量不同。 |
| 单位用量/BOM单耗 | 每一个父项的用量，不是整批生产总需求。 |
| 需求数量 | 已按目标数量计算的本次物料需求。 |
| 实际库存数量/Excel账面数量 | 接入记录中的数量；当前指定企业主库存来源已获单位及比较口径确认。 |
| 可用库存/预留数量 | 仅在相应权威事实存在时显示。未提供不补0，不能依据其他字段自动填入。 |
| 缺口数量 | 有可核实库存时的不足量；无记录或无法核验合计时仍未知。 |
| 来源记录 | 本次使用的数据及适用条件，不等于页面请求时间或实时更新证明。 |

例如单耗为2片、生产目标为10片，则该料需求为20片。库存已知时再进行数量比较；无记录的材料不会因为公式存在而变成库存0。

### 8.2 状态不是放行指令

| 常见状态 | 含义 |
|---|---|
| 所列物料齐套 | 所列范围满足目标物料数量，不代表完整工单或交期批准。 |
| 库存齐套不足 | 有记录的材料存在明确缺口，查看不足行。 |
| 部分数据 · 已知缺料 | 已知项有不足，同时仍有未知或待核验项。 |
| BOM已提供/库存已提供 | 查询成功，不等于已经完成指定数量生产判断。 |
| 需要补充条件 | 当前缺少数量或无法明确对象；按提示补充，不要猜参数。 |
| 暂无已发布数据/无法计算 | 对应事实不足，不能把状态当作数量0。 |
| 独立采购样例 | 当前采购结果标签；在Demo中表示演示采购建议，不是已经执行的采购订单。 |

### 8.3 搜索、筛选与来源

- “搜索物料”支持按名称、编码和规格查找。
- 状态下拉可以选择全部、缺料或未知等项目；文字随本次查询类型变化。
- 点击“物料名称”表头可以切换名称排序。
- 表格较宽时左右滚动查看后续列。
- 点击某行“查看来源”，或结论底部“查看本次分析来源与适用条件”，打开来源区。

来源区只显示返回且允许展示的字段，可能有版本、时点、批次参考或行号。授权工作台隐藏内部路径、完整校验值及未获准的文件名称；看不到这些字段不等于没有内部审计。没有来源字段时省略，不补写日期。

### 8.4 只显示本轮相关结果

- 查询BOM：查看组成和单耗，不自动展示最大产量。
- 查询库存：查看库存及其记录，不自动生成某数量的生产结论。
- 查询生产100片：看100片需求、库存核对和不足。
- 明确询问最大数量：才主动展示上限及相应限制项。
- 查看目录：显示产品列表，不附带上一产品的缺口或目标数量。

完整计算依据仍随结果保存，页面按问题选择相关内容。少显示不相关卡片，不代表可以编造或省略关键未知。

## 第九章 历史会话与恢复

### 9.1 查看历史回答

1. 在左侧找到已完成回答并点击。
2. 查看右侧“历史回答对应结果（非本次请求）”提示。
3. 核对该结果所属产品、范围及原目标数量。
4. 若与活动产品不同，输入框标识不变；需要切换时点击“继续分析此产品”。

历史解释基于当时已保存的结果。需要新核对时明确输入新的合法目标，例如“生产2片KQ-Z112可以吗？”，不要把历史截图当作当前库存证明。

### 9.2 刷新与恢复

在相同浏览器标签页、相同地址和账号，并保留会话记录指针时，刷新或点击“恢复会话”可读取本次对话和跨产品绑定。它恢复原问题、原结果及活动产品，不重新执行所有计算。

- 换地址、换账号、换设备或清除站点数据，不保证自动找到原对话。
- 不能访问其他账号的会话。
- 数据范围版本不匹配时，按页面提示重新分析；不要用新数据解释旧结果。
- 请求取消后可通过恢复确认服务端是否已经完成。

### 9.3 新建分析的区别

“新建分析”开始空白企业对话，活动产品重置，当前浏览器的恢复指针也会清理。它不会删除服务端已有业务历史。

**当前没有承诺一个“列出所有历史会话”的页面入口。** 新建分析之后，不能仅凭再次点击“恢复会话”保证找回全部以前的对话。需要留存重要结果时，先记录产品、范围、问题和时间，按项目组授权方式保存；不要截图或复制其他用户信息。

### 9.4 请求失败与快速切换

连接失败时当前请求显示错误，不改成假成功；旧成功结果只能作为您主动选中的历史查看。

请求尚未完成时切换产品，较晚返回的旧结果不得覆盖新活动产品。需要核对该旧请求时，恢复会话后查找原问题。重试前先恢复，可减少“服务端已完成但浏览器未收到”造成的重复分析。

## 第十章 常见问题与故障处理

### 10.1 查询不到产品怎么办？

先问“有哪些产品？”，从当前账号可见目录选择。使用完整编码或目录中的唯一别称；不在权限范围内时联系账号发放人。目录无产品不代表可以用猜测的型号查询。

### 10.2 为什么目录可能有三个，也可能只有一个产品？

三个主要产品是KQ-Z112、KQ-BHX3588M、DEMO-PMC-01。实际可见范围受账号与入口限制；独立演示版只提供Demo。查询“只查看正式发布的企业BOM产品。”时，应排除演示产品。

### 10.3 为什么1片满足、2片不足？

当前配置最大满足1片。2片目标中MAT-053和MAT-061各缺1片，可在明细中核对单耗、库存与需求。此结论适用于当前业务配置，不等于正式生产放行。

### 10.4 为什么Demo上限是75台？

其四种最终物料库存分别为75、300、150、600件，每台用量分别为1、4、2、8件，四项都仅支持75台。超过75台至少有物料不足。这是演示产品的物料数量上限，不是设备产能。

### 10.5 为什么有些完整产品不能给出全部齐套结论？

存在无库存记录或待核验合计时，不能证明所有材料满足需求。系统仍会计算已有记录材料的需求和差额，不应把其他未知材料写为0。

### 10.6 单独查某物料失败怎么办？

确认您复制的是当前配置可用编码。MAT编号只适用于当前配置；名称不是精确料号。Demo子料独立提问存在当前入口限制，请先查产品，再在表格定位。不要把错误编号不断修改成相近编号。

### 10.7 如何切换或返回产品？

点击输入框附近“当前产品”下拉，或输入“查询演示产品。”“查询BHX3588M。”“回到KQ-Z112。”。等待标识确认更新，再问不带产品的新问题。

### 10.8 如何查看历史，为什么新建后找不到旧对话？

点击左侧已完成回答查看历史；当前对话可刷新恢复。“新建分析”清空本次工作台指针，当前没有全历史会话列表入口。不要把服务端保留历史理解为自动跨设备找回。

### 10.9 为什么0、负数或小数数量被拒绝？

当前生产目标采用大于0的整数。零数量不是生产需求；非法输入应先提示修正，不执行库存计算，也不把0转换为默认1。随后可直接给出合法数量继续。

### 10.10 网页连接失败、超时或服务不可用怎么办？

1. 记录当前产品、分析范围、问题和发生时间。
2. 检查是否使用项目组提供的正确入口，及网络是否正常。
3. 服务恢复后先点击“恢复会话”，检查请求是否已保存。
4. 没有对应已完成结果时，再点击“重试原问题”。
5. 仍失败则向项目组反馈，不发送密码、原始文件或数据库。

系统不会在失败时回退本地假业务数据。等待画面也不代表Tool已经成功。

### 10.11 页面似乎仍是旧版本怎么办？

先保存需要的结果，再尝试普通刷新或浏览器强制刷新。不要先清除站点数据，否则可能丢失当前对话的恢复指针。

若“当前产品”标识、折叠按钮等与本手册不同，请联系项目组确认服务和页面版本。普通用户不需要修改源码或重启数据库。

### 10.12 为什么本地网址不能直接交给别人？

本机地址只访问各自电脑。远程试用需要管理员完成受保护的HTTPS部署并另行提供地址；当前尚未开放。不要将开发服务自行暴露到互联网。

### 10.13 为什么采购量、成本或到货时间没有给出？

可能没有适用的采购或价格事实。两个企业产品目前不保证完整采购数量和成本能力；请用Demo体验采购辅助。没有到货事实时，不会承诺到货日期。
