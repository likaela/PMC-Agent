- 可实施：查询交互、固定演示、任务摘要、业务状态、物料表、独立采购样例、来源、警告、错误和历史切换。
- 待后端核实：所有真实 API 字段、产能、多层 BOM、批次、排产、认证、会话语义。未核实功能仅说明接入条件，不伪造业务入口。

## 页面与模板映射

桌面白色侧栏 232px；主区浅灰 #F5F6FA，24–28px 内边距。主色 #356CF0，白色卡片，12px 圆角、轻边框和阴影。中文系统字体，主标题 30px，表格 13–14px。沿用参考的摘要卡、中部双栏、底部宽表格，不复制无关 KPI、环图和外层展示背景。

- 首页：品牌与用途、开始分析、三种固定场景入口、能力边界与来源说明。
- 分析工作台：四张任务上下文卡；左侧查询和消息记录，右侧所选回答结论/警告/采购建议；下方物料表和来源。没有事实时显示明确空态。
- 手机：导航改为顶栏菜单；摘要卡两列，中部纵向排列，提交后提供跳到结果入口；物料表只在容器内滚动。
- 全局始终显示数据模式。真实模式没有配置契约时明确返回“接口尚未配置”，不请求推测端点，不回退演示数据。

## 组件和数据组织

- AppShell / Icon / StatusBadge：导航、模式、帮助、通用视觉。
- HomeView / WorkspaceView：页面和布局。
- SummaryCards / QueryComposer / MessageList：任务摘要、输入、历史消息选择。
- ResultPanel / MaterialTable / SourceDetails：统一视图模型的只读展示、筛选和来源定位。
- useAgent：AbortController、请求序号、消息结果绑定、重试、取消、模式隔离。
- model.ts / fixtures.ts / mockService.ts / apiClient.ts / responseAdapter.ts：展示模型、固定场景、真实接入边界、校验。

## 数据与交互规则

ABC-1000 / 1,000 台：主板需求 1,000、库存 800、缺口 200 件；电机需求 2,000、螺丝需求 8,000 件，库存及缺口均未提供。固定采购样例 200/100/300 独立标识，不挂到 ABC-1000 分析结论。额外状态均注明人工构造。

输入只匹配列出的完整示例问题；非匹配输入不给固定业务结果。前端不实现业务计算。0、未提供、无已发布事实、网络失败和映射失败独立呈现。每条助手消息绑定完整结果；新请求清空当前结果并显示加载，取消/模式切换使旧请求失效。Enter 发送、Shift+Enter 换行，兼容中文组合输入。

## 验证计划

运行类型检查、生产构建及浏览器回归。覆盖首页入口、主板缺料、库存、零库存/无事实、部分数据、冲突/无法计算、请求重试、取消、来源、历史绑定和模式隔离；检查 1440/1280/1024/390/320 宽度与整页横向溢出。真实后端不在本轮验证范围。
